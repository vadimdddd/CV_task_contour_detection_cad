# CAD Contour Detector

Детекция контуров деталей на инженерных чертежах (PDF/PNG) с использованием компьютерного зрения.

## Особенности
- Автоматическое удаление штампа на чертежах
- Детекция контуров деталей
- Поддержка PDF, PNG, JPG
- Gradio интерфейс для быстрой демонстрации

## Технологии
- Python, OpenCV, PyMuPDF
- NumPy, PIL, Gradio
- Google Colab

## Результаты
- 44/50 чертежей успешно обрабатываются
- Высокая точность детекции контуров
